Engineered to Outperform

Unmatched acceleration, intelligent stream stitching, and session authentication blending.

Parallel HLS Stream Assembler

Parses master and media HLS playlists (.m3u8) and downloads all .ts chunks concurrently with 16 parallel workers, stitching them directly into a single unified .mp4 file.

Engine: Native Tokio HLS Assembler

Dynamic Tail-Chunk Splitting

Eliminates the "99% stall" bug. When any single connection lags behind at the tail end of a download, Orbit automatically bisects the remaining bytes across idle workers.

Optimization: Sub-chunk Auto-Bisect

Authenticated Session Blending

Captures live browser cookies and platform request headers (Referer, Origin, sec-ch-ua) via the WebExtension, completely defeating HTTP 403 Forbidden on streaming portals.

Auth: Live Cookie & Header Passthrough

Multi-Source Mirror Swarming

Pings and probes multiple CDN mirrors simultaneously, streaming chunk ranges across the fastest active servers with dynamic failover if one host throttles.

Networking: Multi-Host Swarm

Token-Bucket Bandwidth Limiter

Smoothly throttle global or per-download transfer rates (e.g. 2 MB/s, 5 MB/s) with zero CPU overhead, ensuring other network applications remain responsive.

Traffic Control: Token-Bucket Rate Limiter

Batch Link Pattern Expander

Quickly ingest hundreds of URLs or use wildcard pattern expansion (e.g. video_[01-20].mp4) to generate batch queues with a single click.

Tooling: Regex & Wildcard Expander

Under the Hood

Architected for extreme I/O efficiency, resilience, and crash recovery.

Direct-to-Disk Chunk Streaming

Rather than buffering downloaded parts in system RAM, Tokio async workers stream byte ranges directly to assigned byte offsets on pre-allocated sparse files. Memory usage remains below 30 MB even during multi-gigabit transfers.

Worker Engine: Tokio + Reqwest (Rustls)

Crash-Proof State Persistence

Every chunk checkpoint, byte counter, ETag, and HTTP header is written to an embedded SQLite database operating in WAL (Write-Ahead Logging) mode. Downloads seamlessly recover after power loss or abrupt network disconnection.

Database Engine: SQLite (WAL Mode)

10Hz Throttled Telemetry Dispatcher

High-speed downloads can produce hundreds of progress events per second. Orbit's Rust core aggregates transfer rates and chunk states into a 100ms batched stream to guarantee zero UI stuttering or dropped frames.

IPC Channel: Tauri 2 Throttled Events

Streaming Cryptographic Validation

Upon transfer completion, a single-pass streaming hasher computes SHA-256, SHA-1, and MD5 checksums concurrently, matching files against remote integrity digests with zero disk re-reads.

Security: Single-Pass SHA256/MD5 Hasher

Frequently Asked Questions

How does Orbit avoid HTTP 403 Forbidden errors on streaming sites?

Orbit's WebExtension captures active session cookies (including cloudflare clearance tokens) and exact platform request headers (Referer, Origin, sec-ch-ua, User-Agent) and forwards them directly to the Rust engine, allowing requests to blend in as legitimate player traffic.

How does Orbit stitch HLS (.m3u8) video streams?

When an HLS playlist is ingested, Orbit recursively resolves the highest bandwidth sub-playlist, downloads all segment chunks (.ts / .m4s) in parallel with 16 worker threads, and stitches them sequentially into a playable .mp4 container on disk.

What platforms are supported?

Orbit provides native 64-bit installers for Windows (.exe setup & .msi) and Linux (.deb package & portable .AppImage).
